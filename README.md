# javascript2-ca The social

This is my submission for the JavaScript 2 course assignment, a social media site that fetches posts, shows users and has follow/unfollow features.

## Description

The webapp registers and log in users using the Noroff API v2 which uses a @stud.noroff.no email to register users. The webapp also has CRUD operations on posts letting the users see, create, edit, and delete their own posts. Users can also see their own profile and other users profiles, giving them option to follow and unfollow eachother. Users can also search for posts, clicking on them to see a single post in a new page. For this assignment uses these technologies:

- Vanilla JavaScript
- ES6 modules
- No frameworks

## Features

- Register User
- Log in user
- CRUD operation on posts
- See own + other profiles
- See single post
- Follow/unfollow users
- Search posts
- See each users posts on profile page

## Build with

- Vanilla JavaScript
- ES6 modules
- HTML
- CSS
- Noroff API v2

## How to run

To run this project locally, you can either use the `git clone` command or github desktop and clone the project.
Project URL: https://github.com/KarlKBerg/javascript2-ca.git
Because of ES6 modules, a server is required for the project to have full functionality. I recommend using VSCode live server extension or `npx serve` if you are using Node.

Copy project URL and run `git clone "project URL"`, then open in VSCode (or your preferred code editor), if you are using vsCode, install live server extension (extensions -> search live server) -> install. Right click on index.html and choose open with live server.
